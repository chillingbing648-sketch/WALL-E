# WALL·E — AI Mental Wellness Companion

WALL·E is a modern **AI-inspired mental wellness web application** designed to help users monitor emotional well-being, track moods, build healthy habits, and engage with a supportive AI companion.

This project was developed as a **BSc IT Final Year Project** and demonstrates the use of modern frontend technologies, data visualization, and interactive UI design to create a meaningful digital wellness experience.

---

# 🌟 Project Overview

Mental health awareness is becoming increasingly important in the modern digital age. WALL·E acts as a **personal emotional wellness assistant** that helps users:

• Track daily moods
• Reflect through journaling
• Build healthy habits
• Visualize emotional trends
• Interact with an AI companion
• Practice breathing and relaxation exercises

The application focuses on **self-awareness, reflection, and emotional balance**.

---

# 🚀 Features

## 🤖 AI Companion Chat

A friendly AI companion that interacts with users and provides supportive responses based on emotional context.

## 😊 Mood Tracker

Users can log their mood daily using emotions such as:

* Happy
* Calm
* Neutral
* Stressed
* Sad

Mood data is stored locally and used to generate emotional insights.

## 📊 Dashboard Analytics

The dashboard visualizes emotional data using interactive charts and statistics.

Includes:

* Mood trends
* Mood distribution
* Habit tracking insights
* Emotional timeline heatmap

## 📅 Emotional Timeline Heatmap

A GitHub-style heatmap visualization showing the user's emotional history across days.

## 📓 Personal Journal

Users can write reflections and maintain a personal emotional journal.

## 🧘 Breathing Exercise

A guided breathing exercise designed to reduce stress and improve mindfulness.

## 🏆 Habit Tracker

Users can track positive habits such as:

* Meditation
* Exercise
* Reading
* Gratitude practice

## 🎨 Modern UI Design

The application features a calming interface with:

* Glassmorphism design
* Smooth animations
* Responsive layout
* Soft wellness color palette

# 🛠 Technologies Used

HTML5
CSS3
JavaScript (ES6)
LocalStorage API
Chart.js for data visualization

The project is designed as a **fully client-side application**, meaning it requires **no backend server**.

# ⚙️ How to Run the Project

1. Download or clone the repository

```
git clone <repository-url>
```

2. Open the project folder.

3. Run the application by opening:

```
index.html
```

in your web browser.

No installation or server setup is required.
